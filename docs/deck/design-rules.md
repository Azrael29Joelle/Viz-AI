# Deck master and design rules (issue #3)

Build the master **once**, before anyone builds slides. Rules come from the lecture on building and delivering a presentation.

## Master spec (proposal; change the colours if the team prefers)
| Item | Rule |
| --- | --- |
| Theme | Our own master, no Office or default Canva theme |
| Font | One sans-serif family (for example Inter or Montserrat), two weights |
| Background | About 90% white (`#F2F2F0`) or about 90% black (`#1A1A1A`); never pure white or black |
| Text colour | High contrast against the background, no harsh colour clashes |
| Accent | One colour only, used for the key number on each slide |
| Body text | At least 36 pt; titles at least 6 pt larger |
| Text limit | At most 6 lines x 6 words |
| Pictures | Pictures over text; put text on the quiet part of an image |
| Animation | Only when it helps; English wipes go left to right |
| Numbers | Every figure comes with a familiar context ("dress up numbers") |
| References | Small IEEE tag on the slide ([1], [2]); full list on the last slide |
| Fictional content | Susan and Adam are labelled "fictional" on screen |

## "Dress up the numbers" (examples from our data)
| Raw number | Dressed up |
| --- | --- |
| An estimated 1.9 million neurons a minute [Saver 2006] | "An estimated 95 million neurons in Susan's 50 minutes" |
| 121 min median DIDO [Royan 2026] | "Two hours in the first hospital before the ambulance even leaves" |
| 26 to 7 min CTA-to-notification [Elijovich 2022] | "From a coffee break to a text message" (check the wording with the team) |
| Door-to-needle 39.4 to 23.0 min in simulation [Koca 2024] | "16 minutes found without hiring anyone, tested on a computer first" |

## Self-check before a slide goes in the deck
- [ ] One message, readable as the title
- [ ] At most 6 x 6 words, at least 36 pt
- [ ] Picture or diagram instead of a paragraph
- [ ] Every number has context and a source tag
- [ ] Same master, same font, same accent colour
- [ ] A speaker's note holds the full sentence, so nobody reads from the slide
